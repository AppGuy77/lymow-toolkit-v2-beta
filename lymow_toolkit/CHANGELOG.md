Lymow Toolkit v2.2.1-beta

**Beta on its own download channel** — recommended for now to people running two or more mowers. It installs
over your current Toolkit (sign-in, maps, settings and history are kept). To go back, install the latest stable release from the
stable releases page: https://github.com/AppGuy77/lymow-toolkit-downloads/releases/latest


- Fixed: the mower's own messages (rain detected, charging abnormal, geo-fence lock, new firmware, its own scheduled start, docked due to an error) had no rows in the notification list and were never pushed. Each now has its own row, in the group it belongs to. The list holds 66 notifications.
- Fixed: with Log events switched off, only the safety guards reached the phone. Every notification is now sent whether or not it is logged.


This beta channel updates independently of the stable Toolkit; report anything odd on the beta repo's Issues page.
